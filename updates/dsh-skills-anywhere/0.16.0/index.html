noteflowai/dsh-skills-anywhere · 0.16.0 · 2026-09-28

Check a skill choice against the installed shortlist

Skills Anywhere 0.16.0 adds a two-step route command. Prepare builds a shortlist of installed skills that can actually be opened; apply checks a saved choice against that shortlist before it is used. The result says whether the pick is selected, absent, below the confidence threshold, stale or invalid. The command does not load or run the skill.

Use it

npm install -g dsh-skills-anywhere@0.16.0
dsh-skills-anywhere route prepare "fill PDF forms" --json > request.json
# Save the recorded choice as response.json, then check it:
dsh-skills-anywhere route apply --request request.json --response response.json

Scope

The route command is CLI-only and checks installed skills on the current machine. Its default confidence threshold of 0.7 is a user-set cutoff, not evidence that any classifier is calibrated. Preparing or applying a route does not execute a skill or send it over the network.

Upgrade and rollback

Install dsh-skills-anywhere 0.16.0 for the new route command. Reinstall 0.15.0 to roll back; saved request and response JSON files remain untouched.
