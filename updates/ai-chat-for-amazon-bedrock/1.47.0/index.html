content-gap insight export as CSV for editorial workflow

Export ranked content gaps as CSV for editorial planning.

Use it

WordPress admin → AI Chat for Amazon Bedrock → Conversations → Content gaps → Download content gaps CSV.

Scope

Administrator access is required. Includes up to 15 ranked groups from the last 30 days of retained exchanges; list filters do not apply. Counts cover gap-contributing exchanges, not all answers. An empty report contains only the header. The CSV contains visitor questions.

Upgrade and rollback

Update to 1.47.0 using the WordPress plugin updater or the release ZIP. Back up the site before upgrading; retain the previous plugin package and backup for rollback. Logging and retention settings continue to apply.
