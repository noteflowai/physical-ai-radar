- **信号**: `含量化指标`
- **为什么重要**: 2027 的限速器大概率不是模型能力，而是平均干预间隔与认证空窗期。

### 2. LeRobotDataset v3.0: a standardised, streamable format for robot learning data

- **主线**: 数据引擎（采集 / 清洗 / scaling） ｜ **证据**: `[O]` ｜ **来源**: [Hugging Face](https://huggingface.co/docs/lerobot/lerobot-dataset-v3) ｜ `2026`
- **关键数字**: `Parquet + MP4 + relational metadata` · `multi-episode packing` · `native streaming for multi-TB datasets`
- **为什么重要**: 格式之争正收敛为数据用 LeRobot v3、资产用 OpenUSD；能一键转换的数据，其资产价值远高于锁在私有格式里的同等小时数。

### 3. Newton: open-source GPU physics engine for robotics (NVIDIA, Google DeepMind, Disney Research)

- **主线**: 仿真与评测（sim2real / 闭环） ｜ **证据**: `[O]` ｜ **来源**: [NVIDIA Developer](https://developer.nvidia.com/blog/announcing-newton-an-open-source-physics-engine-for-robotics-simulation) ｜ `2026`

- **信号**: `有开放代码或权重`
- **为什么重要**: 仿真底座换代且可微，配合 Isaac Lab 的多后端切换，训练与评测可以复用同一套 actuator 配置。

### 4. RoboWorld: fast and reliable neural simulators for generalist robot policy evaluation

- **主线**: 仿真与评测（sim2real / 闭环） ｜ **证据**: `[R]` ｜ **来源**: [arXiv 2607.01060](https://arxiv.org/abs/2607.01060v1) ｜ `2026`

- **为什么重要**: 如果世界模型里的排名能对齐真机排名，评测预算就从人力工时转向 GPU 小时——但真机抽检仍不可取消。

### 5. Isaac Lab-Arena: reusable APIs to author, scale and analyse robot policy evaluations

- **主线**: 仿真与评测（sim2real / 闭环） ｜ **证据**: `[O]` ｜ **来源**: [NVIDIA](https://isaac-sim.github.io/IsaacLab-Arena/main/index.html) ｜ `2026`

### 6. RoboHarness: memory-driven orchestration of heterogeneous robot policies

- **主线**: 系统与编排（长程 / 多策略） ｜ **证据**: `[R]` ｜ **来源**: [arXiv 2607.18060 (Huawei Noah's Ark Lab)](https://arxiv.org/pdf/2607.18060v1) ｜ `2026`

- **为什么重要**: 长程任务的系统形态是编排器加策略池，运维对象从"一个模型"变成"一组可声明的能力边界"。
